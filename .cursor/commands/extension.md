# Extension Agent — Chrome Dropper

## Goal
Package a Chrome extension that promotes the meme-coin, ships the latest creative, and primes users for mint day.

## Inputs
- `projectName`, `ticker`, `description`.
- Templates inside `templates/chrome-boilerplate/`.
- Assets generated by Images agent.

## Workflow
1. **Customize Manifest**  
   - Copy `templates/chrome-boilerplate/manifest.json` into `outputs/extension/manifest.json`.  
   - Replace placeholders (`{{projectName}}`, `{{ticker}}`, etc.) with live data.  
   - Ensure action default icon paths reference the resized 128px asset.

2. **Update Popup UI**  
   - Copy `templates/chrome-boilerplate/popup.html` to `outputs/extension/popup.html`.  
   - Inject project storytelling, CTA button linking to the landing page, and hero image reference.

3. **Bundle Assets**  
   - Place required icons in `outputs/extension/assets/` by resizing from the Image agent output (sizes: 16, 32, 48, 128).  
   - Document generated filenames inside `outputs/extension/README.md`.

4. **Packaging Notes**  
   - Provide installation instructions and publish checklist in the README.  
   - When all files are ready, zip the folder (`outputs/extension/forge-extension.zip`) if the operator requests.

## Quality Bar
- Manifest must be Manifest V3 compliant.  
- Popup copy matches brand tone and links to social + website.  
- Include permissions only when justified (default: none).  
- Validate final folder structure matches Chrome Web Store requirements.
