# KOL Wallet Tracker Landing Page Guide

## Import to V0
1. Open https://v0.dev/new/import.
2. Upload `landing.json` from this directory.
3. When prompted, map asset references to the hero art generated by the Images agent (use `../images/final/1024/kwt-hero.png`).
4. Verify that navigation anchors (`#lore`, `#tokenomics`, `#roadmap`, `#faq`) resolve correctly.

## Customisation Checklist
- Replace the Mint CTA URL with the live Pump.fun or Raydium link once minted.
- Update the Solscan link with the deployed token address.
- Swap the video placeholder with a real Loom/Vimeo demo.
- Add SEO keywords: `Solana KOL tracker, wallet alerts, $KWT`.

## Mobile Optimisation
- Hero image crops to 9:16 on mobile; confirm important details remain visible.
- Stack stats vertically and increase spacing between roadmap items below 768px.
- Use 48px touch targets for CTA buttons.

## Launch Steps
1. Connect custom domain in V0 and enable HTTPS.
2. Set social metadata (OG title, description, image) using the hero art.
3. Add analytics (e.g. Helius or Google Analytics) via V0 integrations.
4. Publish, smoke test on mobile + desktop, then announce via the Twitter thread.

Stay on-brand: neon cyberpunk visuals, fox references, and call-to-action language that screams Solana degen energy.
